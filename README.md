# Analisador Léxico — Compiladores

> Analisador léxico em Flex (Lex) para uma linguagem didática com palavras-chave em português.
> A Flex (Lex) lexical analyzer for a teaching language with Portuguese-based keywords.

---

## 🇧🇷 Português

### Sobre

Trabalho da disciplina de **Compiladores**: um analisador léxico escrito em **Flex** que reconhece os tokens de uma linguagem didática. A linguagem usa palavras-chave derivadas do português, com o sufixo `_mux`.

### Tokens reconhecidos

| Padrão | Token |
|---|---|
| `[0-9]+` | Número inteiro |
| `[a-zA-Z]+` | Identificador |
| `intm` | `INT` |
| `se_mux` | `IF` |
| `senao_mux` | `ELSE` |
| `enquanto_mux` | `WHILE` |
| `faz_mux` | `DO` |
| `para_mux` | `FOR` |
| `{` `}` `;` `>` | Símbolos e operadores |

### Arquivos

```
lexico.l     Especificação Flex com as regras léxicas
lex.yy.c     Scanner em C gerado pelo Flex
a.exe        Binário compilado (Windows)
```

### Compilando

```bash
flex lexico.l
gcc lex.yy.c -o analisador -lfl
```

No Windows, com MinGW:

```bash
flex lexico.l
gcc lex.yy.c -o analisador.exe
```

### Executando

```bash
./analisador < entrada.txt
```

O analisador imprime cada token reconhecido conforme percorre a entrada.
